## 📋 检查清单

### 1. BRD（商业需求文档）

- [ ] 包含**背景**部分：清晰描述项目来源和动机
- [ ] 包含**目标用户**：至少定义2个用户角色
- [ ] 包含**商业/求职价值**：量化说明为什么做
- [ ] 包含**成功标准**：至少3个可衡量的成功指标
- [ ] 文档格式规范，字数 ≥ 800字

### 2. MRD（市场需求文档）

- [ ] 包含**竞品分析**：至少对比3个竞品（Notion AI/标准RAG工具等）
- [ ] 包含**用户分层**：按使用场景分层（学习者/求职者/面试官）
- [ ] 包含**差异化策略**：清晰说明本项目的独特价值
- [ ] 包含**需求优先级**：使用RICE或MoSCoW排序
- [ ] 文档格式规范，字数 ≥ 1000字

### 3. PRD（产品需求文档）

- [ ] 包含**功能列表**：P0/P1/P2分级清晰
- [ ] 包含**用户故事**：Job Stories格式，至少5条
- [ ] 包含**功能流程图**：至少1个核心流程（Mermaid格式）
- [ ] 包含**数据流设计**：RAG检索流程说明
- [ ] 包含**非功能需求**：性能/安全/可维护性
- [ ] 文档格式规范，字数 ≥ 1500字

### 4. 用户旅程图

- [ ] 覆盖**3种核心场景**：知识检索/学习规划/面试模拟
- [ ] 每个场景包含：触发点、步骤、情绪曲线、痛点、机会点
- [ ] 格式清晰，使用Markdown表格呈现

### 5. 数据指标体系

- [ ] 定义**北极星指标**（1个）
- [ ] 定义**L1行为指标**（≥3个）
- [ ] 定义**L2质量指标**（≥2个）
- [ ] 说明各指标的采集方式

### 6. 系统架构图

- [ ] Mermaid图可正常渲染
- [ ] 包含：前端/后端/向量数据库/LLM API/笔记数据源
- [ ] 包含数据流方向标注
- [ ] 附有文字说明（每个模块的职责）

### 7. 迭代Roadmap

- [ ] 包含v0.1/v0.5/v1.0三个里程碑
- [ ] 每个版本有明确的功能范围
- [ ] 格式为时间线或表格
