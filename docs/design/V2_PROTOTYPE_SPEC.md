# 个人知识工作台 v2 可运行原型说明

> 对应信息架构：[V2_INFORMATION_ARCHITECTURE.md](V2_INFORMATION_ARCHITECTURE.md) · 对应需求：[PRD v5 草案](../product/PRD-v5-DRAFT.md) · 原型版本：`v1.0` · 更新日期：2026-08-26 · 状态：项目所有者已验收；非实现原型

## 1. 原型用途

本原型验证 v2 的导航、空间范围、信息层级、图谱展开、Agent 审批和移动核心闭环。它是静态交互设计，不连接真实文件、SQLite、Chroma、模型或 Agent 工具，也不代表功能已经交付。

原型入口：[打开 `prd-v5/index.html`](prototypes/prd-v5/index.html)。建议使用本地静态文件服务预览。

## 2. 运行方式

在仓库根目录启动任意静态服务器，例如：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/docs/design/prototypes/prd-v5/index.html?screen=workspace
```

该命令只提供静态预览，不启动正式前后端。也可以直接打开 HTML，但某些浏览器的本地文件安全策略可能限制交互。

## 4. 可交互内容

- 全局栏和空间树切换主要 screen；
- 工作区空间卡进入选定空间；
- Search/Answer 标签共享查询和范围；
- Document 知识面板切换目录、链接、反链和版本；
- Graph 视图切换结构/关系/聚焦，点击节点展开标题层；
- Graph Focus 通过与视觉边一一对应的文本关系卡查看支持证据，避免只依赖画布命中；
- Agent 计划可以取消部分项、确认执行并撤销；
- Source mode 可以在原位连接和管理副本间切换；
- Recovery 可以重试任务并显示恢复结果；
- 主题按钮切换浅色/深色；
- 移动原型底部导航切换搜索、阅读和审批状态。

交互只改变浏览器 DOM，不写本地文件或发送网络请求。

## 5. 视觉方向

名称：**Knowledge Fieldwork（知识现场）**。

- 保留 v1.x 克制的 Zinc 中性色和单一靛蓝强调色；
- 使用结构线、来源状态和证据标识建立识别性，不使用 AI 紫色渐变；
- 全局栏较窄，空间上下文栏承担真实目录，不通过 hover 隐藏核心信息；
- 页面减少对称功能卡，首页以空间和待处理工作形成不对称布局；
- 图谱使用节点形状、边线型、文字和颜色四种手段区分关系；
- 数字使用 tabular figures；正文控制行宽；主要标题使用更紧的字距；
- 动效只用于面板、展开、状态和焦点，支持 `prefers-reduced-motion`。

## 6. 原型数据说明

原型使用虚构但贴近任务的脱敏示例：Agent 学习、城市研究、产品方法和摄影笔记。数量和日期只为验证布局，不能作为产品指标或已实现数据。

原型中 PM 只在模板列表中作为一个实例，不是默认空间、默认用户或首页主任务。

## 7. 状态覆盖

| 状态 | 覆盖 screen | 表现 |
|---|---|---|
| 默认/成功 | workspace、document、search、graph | 正常主流程 |
| 创建入口 | workspace、source、templates | 新建空间、添加来源和自定义模板的下一步 |
| 处理中 | import | 可辨认阶段和整体进度 |
| 部分成功 | import | 成功、跳过、失败分别统计 |
| 证据不足 | answer | 明确指出当前资料没有覆盖的安全主题 |
| 来源与反链定位 | links | 原文行、工作表单元格和跨空间来源示例 |
| 等待确认 | agent、mobile | 范围、差异、部分拒绝和确认 |
| 权限/来源失败 | recovery | 原文件变化为 0，提供重试/重定位 |
| 可撤销 | agent | 执行结果和撤销 |

## 8. 无障碍要求

- 使用语义化 nav/main/section/aside/button/link；
- 提供 skip link、可见焦点和键盘可操作控件；
- 图谱有文本关系列表，不把信息只放在 Canvas；
- 状态变化使用 `role=status` 或 `aria-live`；
- 关系类型不只依赖颜色；
- 移动触控目标至少 44px；
- 390×844 不出现横向溢出；
- 减少动态模式下取消非必要过渡。
