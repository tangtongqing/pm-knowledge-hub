## 归档规则

1. 不直接修改已经冻结的基线；修正历史错误时创建新的补充说明。
2. 新版本只修改活动文档或新建版本目录，不覆盖旧基线。
3. 每个基线必须记录版本、Git 提交、工作区状态、文件范围和 SHA-256 指纹。
4. 归档文件只有进入版本控制或外部备份后，才具备跨设备恢复能力。
