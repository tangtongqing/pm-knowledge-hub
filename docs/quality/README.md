## 状态规则

- `草案`：质量合同已写出，等待评审；
- `已验收策略`：测试范围和门槛生效，但不代表测试代码存在；
- `已自动化`：有可重复命令和机器可读结果；
- `已实测`：在明确版本、环境和数据上实际运行；
- `通过`：达到对应门槛且无发布否决项；
- `E1 已验证`：必须来自外部用户真实任务，不能由自动化或项目所有者替代。

实际运行结果应进入按日期和里程碑命名的证据目录，不回填覆盖历史报告。
