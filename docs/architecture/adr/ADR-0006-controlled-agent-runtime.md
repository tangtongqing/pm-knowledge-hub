# ADR-0006：采用受控 Agent 工具运行时

## 状态

Proposed — 2026-08-24

## 背景

用户希望通过对话查询、整理和自定义知识操作。通用模型直接访问文件系统、数据库或任意命令会造成越权、误改、提示注入和不可恢复删除；只提供聊天又不能真正降低维护成本。

## 方案比较

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 纯聊天，不允许工具 | 安全简单 | 不能管理知识或形成行动 | 保留为 R0 能力，不是完整方案 |
| 模型直接调用文件/数据库/命令 | 灵活、开发快 | 越权、不可审计、难撤销 | 禁止 |
| 登记工具 + 风险策略 + 人在回路 | 可执行且可控；边界可测试 | 需要计划、审批和撤销模型 | 选择 |
| 完全自治后台 Agent | 自动化程度高 | 与个人资料信任边界冲突 | 不进入 v2 |

## 决策

Agent 运行时只允许调用 Tool Registry 登记的应用服务。每个工具声明：

- 名称、版本、输入/输出 schema；
- 允许对象和 Space/Source 范围；
- 风险级别、是否外发、是否写入；
- 预览/差异生成方式；
- 幂等键、超时和重试策略；
- Undo/Trash/Version 恢复方式；
- 审计字段和去敏规则。

Agent 先生成结构化 Plan；执行器重新校验计划版本、批准、当前策略和目标状态。自然语言响应本身不能授权工具或扩大范围。

## 风险级别

| 级别 | 示例 | 执行规则 |
|---|---|---|
| R0 只读 | 搜索、比较、生成有证据摘要 | 范围通过后可执行；保留来源 |
| R1 可逆创建 | 新建系统笔记、链接、行动 | 展示计划；可由产品决定是否允许本轮确认 |
| R2 批量修改 | 移动、改名、批量改链接/元数据 | 必须逐批确认差异和数量；允许部分拒绝 |
| R3 破坏性/外发 | 删除、覆盖、发送外部服务 | 二次确认、回收站/版本、明确服务商；永久删除不首发 |

## 执行规则

1. AgentRun 创建时固定 `space_scope`，后续不能自行扩大；
2. 计划变化、目标版本变化或确认过期使旧 Approval 失效；
3. 执行使用 `action_id + tool_version + idempotency_key` 防重复；
4. 批量操作逐项返回 succeeded/rejected/failed，不能用总成功掩盖失败；
5. Reference Source 原文件不可写，managed copy 和系统元数据按风险操作；
6. 外部模型只接收完成任务所需的最小内容，Policy Adapter 可直接禁止调用；
7. Audit 追加记录计划、策略、批准、执行、失败和撤销，但不保存密钥或完整私人正文；
8. 工具异常不能回退为任意命令、任意 SQL 或未登记文件访问；
9. 文档中的提示注入内容按普通数据处理，不能改变系统工具权限；
10. 用户可取消未开始 Action，并撤销所有标记 reversible 的成功项。

## 首批候选工具

- `search_knowledge`（R0）
- `open_evidence`（R0）
- `list_broken_links`（R0）
- `create_link`（R1）
- `create_action_note`（R1）
- `apply_relation_suggestion`（R1）
- `rename_collection`（R2）
- `move_documents`（R2）
- `move_to_trash`（R3）

工具是否进入里程碑以 PRD、原型和测试为准，此列表不是已承诺实现。

## 理由

- Agent 复用通用应用服务，不创建第二套业务规则；
- 风险和批准可以自动化测试并进入发布护栏；
- 幂等、版本和 Undo 让本地资料管理可恢复；
- 模板只组合工具和评价规则，不污染知识对象；
- 模型供应商可以替换，不把安全依赖于提示词服从。

## 接受的取舍

- 自动化速度低于完全自治；
- 用户可能产生确认疲劳；
- 每个写工具需要差异、幂等、审计和 Undo 实现；
- 自定义操作只能在受限工具组合内表达。

## 缓解

- R0 无需重复确认；
- R1 是否支持会话级确认由用户测试决定；
- 批量计划支持筛选、部分批准和明确影响摘要；
- 用净节省时间而不是调用次数评估 Agent；
- 高风险门槛不因效率指标下降而降低。

## 复审触发器

- 代表任务的 Agent 净节省时间持续 ≤0；
- 确认疲劳成为主要放弃原因；
- 出现未确认写入、越权或不可恢复数据损失；
- 用户需要的自定义操作无法由安全工具组合表达；
- 团队权限模型获批，需要把 Approval 扩展为多人审批。
